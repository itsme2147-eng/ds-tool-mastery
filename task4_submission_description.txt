This report documents my Data Science Tool Mastery Project, which demonstrates proficiency with the industry-standard tools used in applied AI and machine learning through verified evidence rather than claims. I worked with NumPy, Pandas, SQL via sqlite3, Matplotlib, Seaborn, SciPy, statsmodels, scikit-learn, LightGBM, Git, pytest and Jupyter.

For practical exercises I built a notebook of 31 automated checks, all passing. Each exercise compares my solution with a reference: a PCA written from scratch with the SVD matches scikit-learn, SQL window-function results match Pandas, and a vectorised bootstrap, time-series forecast, ANOVA with Tukey tests, OLS diagnostics and a permutation test are all verified on real public data. A data-leakage exercise shows 0.86 accuracy on pure noise when feature selection is done wrongly, against 0.58 when done inside a pipeline.

The first portfolio piece is an installable Python package with leakage-safe custom transformers, evaluation utilities and a reproducible training command-line tool, covered by 21 passing unit tests and built through incremental git commits. The second is an end-to-end classifier on the public UCI Wisconsin breast cancer data, with success criteria declared before modelling, repeated cross-validation, nested cross-validation, a threshold chosen without touching the test set, calibration, interpretation and a model card. Test ROC-AUC was 0.996 with a 95 percent confidence interval of 0.986 to 1.000. I also report limitations honestly: criteria were met on average but not in every one of 20 random splits, the custom filter was not selected by tuning, deep-learning frameworks are not yet demonstrated, and the model is educational, not clinical. The full project is in my GitHub repository.
